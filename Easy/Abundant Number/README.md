Abundant Number

Description
-----------
Determine whether a positive integer is an abundant number. An abundant number has the sum of its proper divisors (excluding the number itself) greater than the number.

Input
-----
- A single integer n.

Output
------
- Print `true` if the number is abundant, otherwise `false`.

Example
-------
Input: `96`

Expected output (example call in `main.go`):
```
true
```

How to run
----------
```
go run main.go
```

Notes
-----
- Common abundant numbers: 12 (divisors 1,2,3,4,6 sum=16), 18 (sum=21).

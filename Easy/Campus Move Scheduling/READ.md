Write a function ScheduleMove that takes department, itemCount, and truckNumber and returns a formatted scheduling message.

The function creates a move assignment message for the university campus relocation logistics.

Parameters:

department (string): Name of the university department
itemCount (int): Number of items to move
truckNumber (int): Assigned truck number
Returns: Formatted assignment message. Format: Department [department] with [itemCount] items is assigned to truck [truckNumber].
